# Finance Backend API

## Features
- JWT Authentication
- Role-based Access Control (Viewer, Analyst, Admin)
- Financial Records CRUD
- Dashboard APIs (income, expenses, summary)
- Clean architecture (controllers, services, middleware)

## Tech Stack
- Node.js
- Express
- MongoDB

## Run Project
1. npm install
2. add .env file
3. npm run dev
